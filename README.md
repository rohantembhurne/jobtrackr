# JobTrackr

A modern job application tracking dashboard built with React and TypeScript to help job seekers organize, manage, and track their job applications in one place.

## 🚀 Live Demo

https://jobtrackr-ashen-ten.vercel.app

## ✨ Features

* 🔐 Firebase Authentication
* 📋 Add, edit, and delete job applications
* 📊 Application analytics dashboard
* 📌 Kanban board for tracking application status
* 🔎 Live fresher-friendly job feed
* 💾 Firestore database for user-specific application data
* 📱 Responsive dashboard UI
* ⚡ Vercel deployment

## 🛠️ Tech Stack

* React
* TypeScript
* Vite
* Tailwind CSS
* Firebase Authentication
* Firebase Firestore
* Recharts
* Adzuna Jobs API
* Vercel

## 📊 Dashboard

JobTrackr provides an overview of:

* Total Applications
* Applied Applications
* Interviews
* Offers
* Response Rate
* Offer Rate

## 📌 Application Tracking

Applications can be managed through different stages:

**Applied → Interview → Offer → Rejected**

Users can add new applications and update or delete existing applications.

## 🔎 Job Feed

JobTrackr integrates with the Adzuna Jobs API to display live job opportunities and highlights fresher-friendly positions.

## 🔐 Authentication & Data

Firebase Authentication is used for user login, while Firestore stores application data associated with the authenticated user.

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/rohantembhurne/jobtrackr.git
cd jobtrackr
```

### 2. Install dependencies

```bash
npm install
```

### 3. Configure environment variables

Create a `.env.local` file and add your Firebase and Adzuna configuration.

### 4. Start the development server

```bash
npm run dev
```

## 🏗️ Build

```bash
npm run build
```
