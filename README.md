# JobTrackr

JobTrackr is a modern job application tracker built for job seekers to manage applications, track hiring progress, and discover fresher-friendly job opportunities.

## 🚀 Features

- 🔐 Firebase Authentication — Login and Signup
- 📋 Application CRUD — Create, Read, Update and Delete
- 📊 Dashboard with application status counts
- 📌 Kanban Board — Applied, Interview, Offer and Rejected
- 🔎 Live job search using the Adzuna Jobs API
- 💾 Save job listings directly to applications
- 👤 User-specific data with Firebase Firestore
- 📱 Responsive UI
- ☁️ Deployed on Vercel

## 🛠️ Tech Stack

- React
- TypeScript
- Tailwind CSS
- Vite
- Firebase Authentication
- Firebase Firestore
- Adzuna Jobs API
- Vercel
